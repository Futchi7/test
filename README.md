# 禁煙わんこ

禁煙を続けるほど子犬が育ち、マイルストーンごとに着せ替えアイテムが届く禁煙サポートアプリです。
ビルド不要の1ファイル構成で、`index.html` をブラウザで開けば動きます。

## 機能

| 画面 | 内容 |
| --- | --- |
| ホーム | 禁煙経過時間（秒単位）、節約金額、吸わなかった本数、取り戻した時間、目標までの貯金、次のごほうび・次の体の回復 |
| きせかえ | 背景・服・頭・顔・首の5枠。獲得したアイテムを自由に組み合わせ |
| ごほうび | 子犬の成長8段階（0日〜365日）と、1日〜1000日の20個のマイルストーン報酬 |
| からだ | 20分〜15年の回復タイムライン（WHO・米国CDC等の一般的な目安） |
| 設定 | 開始日時、本数、1箱の値段・本数、目標、禁煙の理由 |
| 吸いたい！（SOS） | 3分の衝動タイマー、深呼吸ガイド（4-4-6）、30秒ボール遊び、わんこをなでる、代替行動の提案、自分の理由の表示 |

### 設計上の判断
- **吸ってしまっても成長とごほうびは消えない。** 「1本吸った＝全部失った」という感覚（禁欲違反効果）は再喫煙を招きやすいため、
  「記録だけして続ける」「ここから再スタート」を選べるようにし、再スタートでも累計日数・犬の成長・獲得アイテムは維持します。
- 犬の成長・報酬・節約額は**累計の禁煙時間**、体の回復タイムラインは**今回の連続時間**で計算します。
- 1本あたりの寿命損失は UCL の 2024 年の推計（約20分）を使用。

## データ
記録はブラウザの `localStorage` にのみ保存されます（サーバー送信なし）。ブラウザのデータを消すと記録も消えます。

## 開発
本体は `src/app.html`、犬の画像は `assets/dog.webp`（背景透過済み）。編集後に `./build.sh` を実行すると `index.html` を再生成します。
