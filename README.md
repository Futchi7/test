# いも掘りナビ

さつまいも栽培で一番困る「掘ってみないと収穫適期がわからない」を解決するための PWA(Webアプリ)です。

## できること

- **畝・植付の登録**: 品種(プリセット or カスタム)、植付日、位置情報(任意)を登録
- **収穫適期の予測**: 品種ごとの目安栽培日数と、気象データ(Open-Meteo、APIキー不要)から計算した積算有効温度(Growing Degree Days)をもとに、収穫適期までの進捗率を表示
- **試し掘り・試し刺し・観察の記録**: 日付、大きさの目安、メモ、写真を記録してタイムラインで振り返り
- **土壌センサー連携(実験的機能)**: Web Bluetooth 対応のBLE土壌センサー(水分・地温・電気伝導度)と接続して記録。対応機器がなくても「デモ値で試す」で動作を確認可能
- **通知**: アプリを開いたときに収穫適期が近いことを知らせる(ブラウザ通知)
- **PWA対応**: ホーム画面に追加してアプリのように利用可能

## 前提・注意事項

スマートフォン単体のセンサーで、土の中の芋の形や大きさを直接スキャンすることはできません(地中レーダーのような専用機材が必要です)。このアプリの収穫適期予測はあくまで**簡易推定**であり、最終判断は試し掘り・試し刺しで行ってください。

土壌センサー連携は水分量・地温・電気伝導度といった間接的なデータを扱う補助機能です。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # ビルド
npm run lint     # Lint
```

## 技術構成

- Vite + React + TypeScript
- IndexedDB(`idb`)によるローカル保存(サーバー不要、データは端末内)
- Open-Meteo Archive API(気象データ、APIキー不要)
- Web Bluetooth API(BLE土壌センサー連携)
- vite-plugin-pwa(PWA/オフライン対応)
