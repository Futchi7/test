# RRG Green Grow Log（Googleスプレッドシート版）

植物1株ごとの育成記録を**スプレッドシート（非公開）**で管理し、購入者には**閲覧専用の公開ページ**をQRコードで見せる仕組みです。

## 全体像

```
[あなた] ── スプレッドシートで管理（非公開・編集はここだけ）
              株マスター / 作業ログ / 育て方ガイド / テスターの声 / 今日の作業 / QRラベル
                         │  許可した項目だけ
                         ▼
[購入者] ── QRを読む → 公開ページ（閲覧専用）
              写真・品種・育成日数・育て方・公開した作業ログ・テスターアンケート
                         │  回答
                         ▼
              「テスターの声」シートに保存（個人情報は受け取らない）
```

| 機能 | 内容 |
|---|---|
| まとめて登録 | 植物名・品種・株数を入れると、P-001 から連番で一括登録。株ごとに推測できない「公開ID」を自動で付与 |
| 作業ログ | 日付・管理番号・作業（水やり、水換え、肥料、植え替え…）を記録。「公開」のチェックを外した記録は購入者に見えない |
| 今日の作業 | 育て方ガイドの間隔日数から、期限が来た水やり・水換え・肥料を一覧にする |
| QRラベル | 公開中の株のQRを4列で並べたシートを作る。そのまま印刷できる |
| 公開ページ | 写真、育成日数、育て方のポイント、育成記録、テスターアンケート |

## 安全のための設計

- **編集できるのはスプレッドシートだけ**です。公開ページには編集や削除の機能がありません。
- 公開ページは、推測できない24文字の公開IDでしか開けません（P-001 のような番号では開けない）。
- 公開ページに出すのは、決めた項目だけです。「メモ（非公開）」、仕入れの情報、出荷先は出ません。
- 写真はDriveに置いたまま、共有設定は不要です。サーバー側で縮小画像を埋め込むので、**元の写真ファイルや位置情報は外に出ません**。
- アンケートは長さと値を検証し、スプレッドシートの数式として実行されないように保存します。同じ株からの送信は1時間に5回までです。
- 自動テスト12件で、上記の動作を確認済みです（`node test/run.js`）。

## セットアップ（初回だけ・約15分）

1. **Googleドライブで新しいスプレッドシートを作る**（名前の例: `RRG Grow Log`）
2. メニューの **拡張機能 → Apps Script** を開く
3. `コード.gs` の中身をすべて消して、このフォルダの **`Code.gs`** を貼り付ける
4. 左の「ファイル」の **＋ → HTML** で `Care` を作り、**`Care.html`** を貼り付ける。同じように `NotFound` を作り、**`NotFound.html`** を貼り付ける
5. 左の歯車（プロジェクトの設定）で **「appsscript.json」マニフェスト ファイルをエディタで表示する** をオンにし、`appsscript.json` の中身を **`appsscript.json`** で置き換える
6. 保存（Ctrl+S）してから、スプレッドシートを再読み込みする。上に **🌿 Grow Log** メニューが出る
7. **🌿 Grow Log → ① 初期セットアップ** を実行する
   - 初回は承認画面が出ます。「このアプリは Google で確認されていません」と出たら、**詳細 → （プロジェクト名）に移動** を選びます。自分で作ったスクリプトなので問題ありません
8. Apps Script で **デプロイ → 新しいデプロイ → 種類: ウェブアプリ**
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
   - デプロイ後に表示される `https://script.google.com/…/exec` のURLをコピーする
9. **🌿 Grow Log → ② 公開ページのURLを登録** に貼り付ける

## 毎日の使い方

| やること | 操作 |
|---|---|
| 株を登録する | 🌿 Grow Log → **まとめて登録**（例: ゴールデンポトス / ポトス / 3号 / 育成中 / 50） |
| 写真を付ける | 写真をDriveにアップロードし、そのファイルのURLを「株マスター」の「写真」列に貼る |
| 作業を記録する | 「作業ログ」に日付・管理番号・作業を入力する。購入者に見せたい一言は「公開メモ」、見せたくないものは「メモ（非公開）」に書く |
| 今日やることを見る | 🌿 Grow Log → **今日の作業を更新** |
| ラベルを印刷する | 🌿 Grow Log → **QRラベルを作成** → ファイル → 印刷。**最初に1枚だけ印刷して、iPhoneとAndroidで読めるか試す** |
| 出荷したとき | 「ステージ」を **出荷済み** にして「出荷日」を入れる（ラベルと今日の作業の対象から外れる。公開ページは購入者が引き続き見られる） |
| 購入者に見せたくない株 | 「公開」のチェックを外す |
| 育て方を直す・品種を増やす | 「育て方ガイド」を編集する（ポトス、モンステラ、サンスベリアは入力済み。内容は必ず自分で確認してください） |

## 必ず守ること

- **コードを更新するときは「新しいデプロイ」を作らないでください。** URLが変わり、印刷済みのQRがすべて使えなくなります。
  更新は **デプロイ → デプロイを管理 → 鉛筆アイコン → バージョン: 新バージョン → デプロイ** で行います（URLは変わりません）。
- QR画像は外部サービス（api.qrserver.com）で作っています。送られるのは公開ページのURLだけです。
- 公開ページの上部に、Googleの「このアプリケーションは…別のユーザーによって作成されました」という帯が表示されます。Apps Scriptの仕様で消せません。気になる場合は、将来、独自ドメインのサイトから転送する形にします。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `Code.gs` | メニュー、登録、QRラベル、今日の作業、公開ページ、アンケート受付 |
| `Care.html` | 購入者向けの公開ページ |
| `NotFound.html` | 公開IDが違う・非公開のときのページ |
| `appsscript.json` | 権限とWebアプリの設定 |
| `test/run.js` | Googleの環境を模した自動テストとプレビュー生成（`node test/run.js`） |
